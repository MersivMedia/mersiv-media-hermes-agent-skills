## Install

Copy any skill directory into `~/.hermes/skills/<category>/`. Hermes picks skills up automatically on the next session.

```bash
git clone https://github.com/MersivMedia/mersiv-media-hermes-agent-skills.git
cp -r mersiv-media-hermes-agent-skills/creative/seedance-video ~/.hermes/skills/creative/
```

## Configuration

Secrets are read from `~/.hermes/.env` (e.g. `REPLICATE_API_TOKEN`, `ELEVENLABS_API_KEY`, `RUNPOD_API_KEY`). No credentials ship in this repo.

Account-specific values are placeholders you replace with your own:

- `<DRIVE_FILE_ID>` / `<DRIVE_FOLDER_ID>`: Google Drive IDs
- `<volume-id>`: RunPod network volume ID
- `<your-account-email>`: cloud account login
- `BRAND_BG_FILE_ID`, `BRAND_CHARACTER_FOLDER_ID`: env vars used by the `brand-youtube-pipeline` scripts

The `brand-video` and `notebooklm-*` skills are built around one [brand]; treat them as worked examples to adapt.
